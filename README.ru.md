# warehouse-api

REST API для учёта складов, товаров и остатков.

## Быстрый старт

```
cp .env.example .env
make up
```

Поднимет Postgres и сам API в докере, применит миграции при старте. API слушает `:8080`, доки — на `http://localhost:8080/swagger/index.html`.

Погасить всё:

```
make down
```

## API

### Склады

| Метод | Путь | Описание |
|---|---|---|
| GET | `/warehouses` | Список складов |
| GET | `/warehouses/{id}` | Склад по id |
| POST | `/warehouses` | Создать склад |
| DELETE | `/warehouses/{id}` | Удалить склад |

### Товары

| Метод | Путь | Описание |
|---|---|---|
| GET | `/items` | Список товаров |
| GET | `/items/{id}` | Товар по id |
| POST | `/items` | Создать товар |

### Остатки

| Метод | Путь | Описание |
|---|---|---|
| GET | `/stock` | Все остатки |
| GET | `/warehouses/{id}/stock` | Остатки конкретного склада |
| GET | `/items/{id}/stock` | Остатки конкретного товара по всем складам |
| POST | `/stock` | Создать запись остатка (склад + товар + количество) |
| PATCH | `/stock` | Изменить количество на дельту (пополнение или списание, может быть отрицательной) |
| POST | `/stock/transfer` | Перевод товара между складами одной транзакцией |
